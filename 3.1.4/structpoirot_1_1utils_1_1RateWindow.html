Detailed Description

Lazy windowed estimator of energy per system busy microsecond.

The window is opened on first use and refreshed only when it has been open for at least the configured window duration, so it can be driven by call-boundary reads without a dedicated sampler thread.

Refresh the rate when the window has been open for window_us.

Samples with no positive energy and busy-time deltas are discarded, but the window is always reset once it elapses so idle periods cannot poison the rate.
