Detailed Description

Class for monitoring GPU metrics and energy consumption.

Supports NVIDIA GPUs via nvidia-smi and AMD GPUs via rocm-smi. Provides methods for reading GPU utilization, memory usage, power, and energy.

◆ compute_process_share()

double poirot::utils::GpuMonitor::compute_process_share ( pid_t pid,
uint64_t now_us,
const std::vector< NvmlProcessUtilizationSample > & samples,
const std::vector< NvmlProcessInfoV2 > & running )
static

Compute a process's share of GPU work.

Keeps only the newest fresh sample per PID. Uses the process's fresh SM utilization sample normalized over the newest fresh samples of all PIDs. When the process has no fresh sample, falls back to its memory ratio over the running-process list.

Parameters
pidProcess ID.
now_usCurrent time in microseconds in the SAME clock domain as sample timestamps (system/realtime epoch microseconds, not steady clock).
samplesPer-process utilization samples.
runningProcesses with GPU compute contexts.
Returns
Share in [0, 1].

◆ read_process_energy_uj()

double poirot::utils::GpuMonitor::read_process_energy_uj ( pid_t pid = 0)

Read per-process accumulated GPU energy in microjoules.

This method calculates the energy consumption attributed to a specific process based on its GPU memory usage ratio compared to system-wide GPU usage. Uses time-based integration of power measurements.

Parameters
pidProcess ID to query (default: current process).
Returns
Accumulated energy attributed to the process in microjoules.

double poirot::utils::GpuMonitor::read_process_utilization_us ( pid_t pid = 0)

Read the accumulated attributed GPU utilization x time.

Monotonic accumulator in microseconds of attributed share time. The per-call utilization is (end - start) / wall time.

Note
The accumulator is per-monitor; the pid argument is accepted for API symmetry.
Returns
Accumulated attributed share time in microseconds.
