double thread_cpu_delta_us,
double rate_uj_per_busy_us )
static

Attribute a measured package-energy delta to a thread.

Uses the interval path when a measurable energy delta and at least MIN_INTERVAL_US of system busy time are available; otherwise falls back to the measured rate. Returns 0 when no usable data exists.

Parameters
delta_energy_ujPackage energy delta over the call interval.
delta_busy_usSystem busy CPU time delta over the call interval.
thread_cpu_delta_usThread CPU time delta over the call interval.
rate_uj_per_busy_usFallback energy rate in uJ per busy us.
Returns
Attributed thread energy in microjoules.

double poirot::utils::RaplMonitor::parse_proc_stat_busy_us ( const std::string & line,
long clk_tck )
static

Parse the aggregate cpu line of /proc/stat into busy time.

Busy time is user + nice + system + irq + softirq + steal; guest time is already included in user/nice and must not be added again.

Parameters
lineThe first line of /proc/stat (starting with "cpu").
clk_tckTicks per second (_SC_CLK_TCK); falls back to 100 if <= 0.
Returns
Busy CPU time in microseconds, or 0.0 on parse failure.
