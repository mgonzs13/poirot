Detailed Description

Main class for the Poirot profiler. This class provides methods to start and stop profiling, retrieve statistics, and manage system and process information. It is designed to be thread-safe and efficient for use in multi-threaded applications.

Start profiling a function.

Parameters
function_nameName of the function being profiled.
fileSource file name.
lineLine number in the source file.
include_childrenWhen true, the CPU time and attributed energy of any child process reaped during the call are folded into the call's values (see PROFILE_FUNCTION_WITH_CHILDREN). Uses getrusage(RUSAGE_CHILDREN), which is process-wide: overlapping profiled windows may mis-attribute child usage.
